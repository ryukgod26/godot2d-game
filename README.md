# Enemy Hunter

## About The Project

It was my first game I crated on godot and I am still continuing it to make it better. I have added a winter theme level and now player can also attack with his sword to damage the enemy. Also Added a new cool winter theme Particle Emitter which looks very good. I was also trying to add footstep sound but it did not work (Will be availaible in next update).

### Controls
- Move: Arrow Keys 
- Jump: Space Bar
- Pause: Pause button shown in the HUD
- Left Mouse Button: Attack


## Usage

1. Move your character using the arrow keys or A/D
2. Jump with Space
3. Jump on enemies twice to defeat them
4. Collect coins to increase your score
5. Avoid hazards and keep your health above zero
